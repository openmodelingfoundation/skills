## Definitions and method

Each row has a unique `record_id` and a `count`, a nonnegative integer in units
of individual items. There are no missing values or missing-value codes. The
fixture author manually assigned counts 1, 2 and 3 to create an arithmetic
example. No original measurements, filtering or analytical transformation exist.
The reported total is six, obtained by adding those three counts. Check it by
reading `data.json` and adding the counts manually; no environment is required.
